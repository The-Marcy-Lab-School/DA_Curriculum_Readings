3. Memory is temporary; files persist

While Python runs
spots = [...]
live value in memory
→
After writing
spots.json
stored representation on disk

The file does not keep the original live Python object running. It stores a representation of the data. Later, Python can read that representation and build a fresh usable value.

You close Python after creating a list but never write it anywhere. What should you expect next time?

4. Three formats, three useful shapes

JSON

Shape: nested keys, values, arrays.

Think: structured records, APIs, AI-tool data.

CSV

Shape: flat rows and columns.

Think: spreadsheet-style tables.

TXT

Shape: whatever convention you define.

Think: simple or custom line-based data.
