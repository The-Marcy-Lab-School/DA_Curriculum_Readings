2. Recall: code can repeat work

Suppose an outer loop runs 3 times and an inner loop runs 2 times for every outer pass. How many times does the inner action happen?

Why recall loops? You already know how to repeat an action. Functions add another useful idea: name a job once, then call that job whenever you need it.

7. The big distinction: display vs. hand back

These functions can look similar when you run them, but they behave differently when another line needs the result.

def show_discount(price): print(price - 2)
def get_discount(price): return price - 2

You need to save the discounted number and multiply it later. Which function is designed for that?

8. Debug the invisible None

def square_display(x): print(x * x) saved = square_display(3) print(saved)

The function displays 9, but because it has no explicit return, the call's return value is None. Visible output and returned output are not the same thing.
