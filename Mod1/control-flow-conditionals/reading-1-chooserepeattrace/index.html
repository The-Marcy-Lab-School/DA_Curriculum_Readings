Variables and data types matter because conditions compare values. A program can make different choices depending on the value it sees.

3. Conditionals choose a path

An if asks the first question. An elif asks another question only if an earlier branch did not run. An else handles the remaining case.

Check if
→
if needed, check elif
→
otherwise else

A delivery app sees distance = 6. What prints?

if distance > 10: print("far") elif distance > 3: print("nearby") else: print("close")

4. Trace first. Run second.

A reliable habit is to predict the branch before revealing output.

battery = 38 if battery >= 70: print("high") elif battery >= 25: print("medium") else: print("low")

Tracing habit: read from top to bottom. Once a branch runs, the rest of that if/elif/else chain is skipped.

6. range(): watch the stopping boundary

range(n) starts at 0 and stops before n. So the stop value itself is not produced.

What does this print?

for step in range(4): print(step)

7. while: repetition controlled by a condition

A while loop checks its condition before each pass. Something in the loop usually needs to change so that the condition eventually becomes false.

9. Two ideas, one powerful pattern

A loop can visit each item while a conditional decides what to do with that item.

sizes = [2, 7, 4] for size in sizes: if size >= 5: print(size, "large") else: print(size, "small")
