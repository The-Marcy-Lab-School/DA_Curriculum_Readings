Choose, Repeat, Trace

A movie theater has a list of tonight's movies. A small Python program, called a script, looks at each movie, one at a time. Is the movie longer than 150 minutes? Then it gets a long time slot. If not, it gets a regular slot. Choosing the slot is a conditional. Doing it again for every movie is a loop.

1. The big idea

Going through a list and deciding what to do with each item is one of the most common jobs in code. Data work uses it to pick out the rows you need and mark the bad ones. Later, you will put one loop inside another and wrap the whole pattern into code you can reuse.

Python runs the same steps in the same order every time. So if you read code carefully, you can say what it prints before you run it. That skill is called tracing, and this reading practices it.

2. Reading Python

This is your first look at Python code. Here are the pieces every file in this reading uses.

  • runtime = 98 stores the value 98 under the name runtime. A name that holds a value is a variable. Here = means "store," not "is equal to."
  • print(runtime) shows the value on the screen. print("Runtime:", runtime) shows both values, with a space between them.
  • 98 is a number. "98", in quotes, is a string: text. You met these data types before.
  • > >= < <= == != compare two values. Each comparison gives back True or False. Two equals signs, ==, ask "are these equal?" and != asks "are these different?"
  • [98, 165, 122] is a list: several values kept in order, inside square brackets.
  • A line that starts with # is a note for people. Python skips it.
  • A line that ends with a colon : owns the lines under it that are pushed in by 4 spaces. That pushed-in group is called a block. You will see this with if, for, and while.

Running a file means Python does every line, top to bottom. The Run button shows what it prints. On your own laptop you'd type python3 theater_notes.py in the terminal.

# Lines that start with # are notes for people. Python skips them.
movie = "Moonlight Run"
runtime = 98

print(movie)
print("Runtime:", runtime)
print(runtime > 150)
print(runtime == 98)

runtimes = [98, 165, 122]
print(runtimes)

3. if / elif / else: exactly one path runs

A conditional is code that checks a condition, True or False, and picks which code runs next. Each possible path is a branch: the block under an if, an elif (short for "else if"), or an else.

Python reads the chain from top to bottom. It stops at the first branch whose condition is True and runs only that block. An else runs only when every condition before it was False. So exactly one branch runs.

The theater's lobby screen tells people how soon their movie starts. In lobby_screen.py, the movie starts in 25 minutes.

Predict: what does lobby_screen.py print?

minutes_left = 25

if minutes_left >= 60:
    print("plenty of time")
elif minutes_left >= 15:
    print("head over soon")
else:
    print("starting now")
head over soon

4. for loops and range()

A loop repeats a block of code. A for loop repeats it once for each item in a list. One pass through the loop is an iteration. The pushed-in code that runs on every pass is the loop body.

In showtimes.py, the name show holds the current item. On the first pass, show is "4:15". On the next pass, it is "7:00".

Predict: how many lines does showtimes.py print?

showtimes = ["4:15", "7:00", "9:45"]

for show in showtimes:
    print("Showing at", show)
Showing at 4:15
Showing at 7:00
Showing at 9:45

How many lines print?

Sometimes you want to repeat a set number of times instead of going through a list. range(n) makes n numbers to loop over. It starts at 0 and stops one step before n. So range(3) gives 0, 1, and 2. The stop number itself is never included.

5. Off-by-one errors: wrong by exactly one

The theater has seven screens. Before the doors open, screen_check.py should print one line for each screen. It prints six.

for screen in range(6):
    print("checking screen", screen + 1)
checking screen 1
checking screen 2
checking screen 3
checking screen 4
checking screen 5
checking screen 6

range(6) gives 0 through 5. The file prints screen + 1, so the last line says 6. Screen 7 never gets checked. This is an off-by-one error: a loop that runs one time too many or one time too few, because a start or stop number is one step off.

Python shows no error here. The file runs and finishes, so nothing on the screen says anything is wrong. Two habits catch it:

  1. Trace the first and last passes by hand. The first should say screen 1, and the last should say screen 7.
  2. Count the lines that print. Six is not seven.

  3. range() stops one before its number. Type the number that makes it stop right after 6. Type only the number.

6. while loops: check, run, check again

A while loop repeats for as long as its condition stays True. Python checks the condition before every pass:

Check the condition
the body runs only when the check is True
Run the loop body
the body changes a value the condition uses
Check the condition again, with the new value

Before the doors open, a lobby sign counts down 10 minutes at a time. The last line of countdown.py is minutes = minutes - 10. Python works out the right side first: the current minutes minus 10. Then it stores that result back under the name minutes. So 30 becomes 20.

Predict: what does countdown.py print?

minutes = 30

while minutes > 0:
    print(minutes)
    minutes = minutes - 10
30
20
10

What prints, one number per line?

7. Loop + conditional together

Now put the two ideas together, like the theater script from the start. The loop visits every movie. The if inside the loop body decides the slot for the current movie. Python checks that condition again on every pass.

Predict: how many movies does runtimes.py put in a long slot?

runtimes = [98, 165, 150]

for runtime in runtimes:
    if runtime > 150:
        print(runtime, "long slot")
    else:
        print(runtime, "regular slot")
98 regular slot
165 long slot
150 regular slot

9. Wrap-up

  • Read an if/elif/else chain top to bottom, and name the one branch that runs.
  • Count a loop's passes one at a time instead of guessing the total.
  • Check the first and last pass against what you meant. That is where an off-by-one error shows up.
