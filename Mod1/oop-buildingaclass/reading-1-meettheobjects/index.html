5. Read the shape of a class

Fresh example—different from the lecture code you'll see later:

class FestivalPass:
    def __init__(self, owner, balance):
        self.owner = owner
        self.balance = balance

    def needs_refill(self):
        return self.balance < 5

pass_a = FestivalPass("Mina", 18)

Trace the creation call: "Mina" flows into owner, then self.owner = owner stores it on this new object. The same thing happens to 18 and balance.

What is the value of pass_a.owner?

6. The tough part: what does self point to?

Change which object calls the method, and self changes with it.

pass_a.needs_refill()

Inside the method:
self → pass_a
self.balance → 18
18 < 5 → False

pass_b.needs_refill()

Inside the method:
self → pass_b
self.balance → 3
3 < 5 → True

When Python runs pass_b.needs_refill(), what does self.balance mean?

12. Required bridge to lecture/lab
