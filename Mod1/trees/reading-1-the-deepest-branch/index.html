The Deepest Branch

In a guessing game, one player thinks of an animal. The other asks yes-or-no questions, like "Can it fly?" Each answer leads to a new question, until someone makes a guess. Draw every question and answer, and the picture branches like an upside-down tree. Programs store data in this shape too.

1. The parts of a tree

Here is the guessing game drawn out. Going left means the answer was yes. Going right means no.

Each box is a node: one item in the tree, holding a value. Each line joining two nodes is an edge. The tree words come from family trees:

  • The root is the one node at the top, with nothing above it: "Can it fly?"
  • A node's children are the nodes joined to it one level down. That node is their parent. "Is it big?" is the parent of eagle and sparrow.
  • Siblings are nodes with the same parent, like eagle and sparrow.
  • A leaf is a node with no children. In this game, every leaf is an animal, which is a guess.

Every node here has at most two children, a left one and a right one. A tree with that rule is a binary tree. Folders on a laptop and the parts of a web page are trees too. "How deep does this tree go?" is a common interview question, and this reading builds up to the answer.

3. Build the tree in Python

A small class can hold one node. Each Node object stores its text and its two children. A leaf has no children, so its left and right are None.

New in this file: left=None in the def line gives the parameter a default value. If a call leaves it out, as in Node("frog"), it is None.

The file builds the tree from the bottom up, because each node needs its children to exist before it can store them. To read root.right.left, start at root, go to its right child, then to that node's left child.

class Node:
    def __init__(self, text, left=None, right=None):
        self.text = text
        self.left = left    # the "yes" answer
        self.right = right  # the "no" answer

legs = Node("Does it have legs?", Node("frog"), Node("fish"))
water = Node("Does it live in water?", legs, Node("dog"))

print(root.right.text)
print(root.right.left.left.text)

4. Visit every node: traversal

A traversal visits every node in a tree once, in a set order. One common order is pre-order: visit the node, then everything on its left side, then everything on its right side.

"Everything on its left side" is a smaller tree with the left child as its root. So the same steps work on it. That is recursion: a function that calls itself on a smaller piece of the problem. show prints a node, then calls show on each child. When it reaches a missing child (None), it returns without calling itself again. That stopping branch is the base case.

Predict: in the output of show_all.py, which line comes right after sparrow?

class Node:
    def __init__(self, text, left=None, right=None):
        self.text = text
        self.left = left    # the "yes" answer
        self.right = right  # the "no" answer

legs = Node("Does it have legs?", Node("frog"), Node("fish"))
water = Node("Does it live in water?", legs, Node("dog"))
big = Node("Is it big?", Node("eagle"), Node("sparrow"))
root = Node("Can it fly?", big, water)

def show(node):
    if node is None:
        return
    print(node.text)
    show(node.left)
    show(node.right)

5. The deepest branch

The depth of a tree is how many levels it has, counted from the root down to its farthest leaf. A tree with only a root has a depth of 1. In the game, depth tells you the most questions and guesses a player could need.

Look at the picture in section 1. Count the levels from "Can it fly?" down to frog. What is this tree's depth?

Code can't look at a picture. It only sees one node at a time. So max_depth uses a recursive rule:

  1. Base case: a missing node (None) has depth 0.
  2. Recursive case: ask the left child for its depth, and ask the right child for its depth.
  3. Return 1 (for this node) plus the larger of the two answers.
class Node:
    def __init__(self, text, left=None, right=None):
        self.text = text
        self.left = left    # the "yes" answer
        self.right = right  # the "no" answer

legs = Node("Does it have legs?", Node("frog"), Node("fish"))
water = Node("Does it live in water?", legs, Node("dog"))
big = Node("Is it big?", Node("eagle"), Node("sparrow"))
root = Node("Can it fly?", big, water)

def max_depth(node):
    if node is None:
        return 0
    left = max_depth(node.left)
    right = max_depth(node.right)
    return 1 + max(left, ____)

7. Wrap-up

  • A tree is nodes joined by edges, starting from one root. A binary tree gives each node at most two children.
  • A traversal visits every node once. Pre-order visits a node, then its left side, then its right side.
  • Depth is 1 plus the larger of the two children's depths, and a missing child counts as 0.

New situation: to tell an eel from a fish, you replace the fish leaf with a new question, "Is it long and thin?". Yes leads to eel. No leads to fish.

Predict: what does max_depth_eel.py print?

class Node:
    def __init__(self, text, left=None, right=None):
        self.text = text
        self.left = left    # the "yes" answer
        self.right = right  # the "no" answer

thin = Node("Is it long and thin?", Node("eel"), Node("fish"))
legs = Node("Does it have legs?", Node("frog"), thin)
water = Node("Does it live in water?", legs, Node("dog"))
big = Node("Is it big?", Node("eagle"), Node("sparrow"))
root = Node("Can it fly?", big, water)

def max_depth(node):
    if node is None:
        return 0
    left = max_depth(node.left)
    right = max_depth(node.right)
    return 1 + max(left, right)

print(max_depth(root))
5

In an interview, a good answer to "find the depth of this tree" says the rule out loud: a node's depth is 1 plus the larger of its children's depths, and a missing child counts as 0.

Next, trees can keep their values in sorted order, which makes searching them fast. That kind of tree is called a binary search tree.
