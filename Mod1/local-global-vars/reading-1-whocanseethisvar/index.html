Who Can See This Variable?

Imagine two functions helping run a music festival. One function creates a temporary calculation for a single ticket. Another quietly reaches outside itself for a value someone else set earlier. Both may work today—but which one can you trust when the program moves?

8. Required bridge to lecture + project

You just practiced three habits: identify where a name is created, distinguish a returned value from a local name, and notice when a function secretly depends on outside state. In lecture, you will use those habits to trace actual Python scope errors, read a global from a function, and refactor a hidden global dependency into a parameter. The project connection is the same design habit: functions such as read_batch_file, validate_line, and process_transactions need to work from their parameters rather than secretly reaching for outside variables.
