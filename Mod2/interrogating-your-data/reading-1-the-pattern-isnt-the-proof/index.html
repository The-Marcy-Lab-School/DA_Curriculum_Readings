The Pattern Isn't the Proof

Volunteers counted the street trees in four parts of town. The neighborhood association will plant new trees where the file shows the fewest. In the file, that is West, with only 2 trees. But a pattern in a file is not proof about the streets. Maybe West has few trees. Maybe volunteers walked only a few of its blocks.

2. Read the source note, then count the rows

A pattern can be real in the file and still be wrong about the world. So before you trust it, check the data underneath. Start with the source note: the short document that comes with a dataset and says who collected it, when, and how. Here is the one for the tree count.

Street Tree Count, spring Who counted: adult volunteers in North, East and West, over two Saturdays. A middle-school club counted South on one rainy morning. How: volunteers picked blocks in their area. For each tree, they wrote the species and measured the trunk in inches.

The note answers some questions and leaves others open. It never says which blocks were picked. Here is the file itself.

area,species,trunk_inches,counted_by North,maple,14,adults North,oak,22,adults North,maple,9,adults South,,6,club South,maple,11,club South,,8,club South,,5,club East,oak,19,adults East,,12,adults East,linden,15,adults West,maple,20,adults West,oak,25,adults

Count the rows in each area before you quote a number. value_counts() lists each area with its row count, biggest first.

Predict: which line comes last in the output of cell 1?

import pandas as pd
trees = pd.read_csv("trees.csv")

West has 2 rows. The other areas have 3 or 4. That could mean West has few trees. It could also mean volunteers picked fewer blocks there. The file can't tell you which. To sort out problems like this, use a three-part checklist:

Checklist rowThe question it asks
OriginWho collected this, and how?
CompletenessWhat's missing, and why?
BiasWho or what got under-sampled, meaning counted less than the rest?

3. Count the blanks in each group

The species column has 4 blanks in all. That total hides where the blanks are. A gap that hits one group harder can throw off any comparison between groups, so count the blanks by group.

New in this cell: trees["species"].isna() makes a column of True and False. .groupby(trees["area"]) splits those values by area. .sum() adds them up in each area. True counts as 1, so each sum is that area's number of blanks.

Predict: which areas show up in the output of cell 2?

trees["species"].isna().groupby(trees["area"]).sum()
area
East     1
North    0
South    3
West     0
Name: species, dtype: int64

Three of South's 4 trees have no species, and the club counted South. If the association compares tree types across areas, South's numbers will look thin. That is a Completeness problem with a likely Origin cause. Both are worth a question.

4. Ask checkable questions

A question about data is only useful if someone can answer it. The person who can is the data steward: the person or team who looks after the data. Here, that is the association volunteer who organized the count.

"Is this data accurate?" sounds careful, but the steward can't answer it with a fact. That is a generic question. A checkable question is specific enough to get a real answer. Use this table to tell them apart.

CheckableGeneric
Names a specific method or numberCould apply to any dataset at all
A data steward could answer itNo specific fact to check
Ties to something you already foundSounds thoughtful, answers nothing

Some checkable questions the file can answer with code, such as "How many West rows are there?" Others only the source note or the steward can answer, such as "Which blocks did West's volunteers pick?"

Rewrite a generic question

Here is a generic question about the blanks: "Why is data missing?"

  1. Name the group: say which area the blanks are in.
  2. Name a number or a method: how many blanks, or how that area was counted.
  3. End with a question mark. Write one sentence, at least 8 words.
  4. Press Check my question to see which parts your question has.

Why: a steward can only answer a question that points at a real fact.

Need a hint?

Look back at the source note. What was different about how South was counted? Ask whether that difference explains the blanks you found in cell 2.

6. Wrap-up

  • Read the source note first. It answers some questions and shows which ones are still open.
  • Check the data with Origin, Completeness and Bias. Count rows and blanks by group in code before you quote a number.
  • A checkable question names a group, a number or a method, and a data steward could answer it with a fact.

New situation: the neighborhood association runs a second count in the fall. This time a phone app counts South from photos. Volunteers count every other area on foot. The app finds twice as many trees in South as before. Which question should go to the data steward?

In interviews, "What would you ask before trusting a finding from a dataset?" is a common question. A strong answer names who made the data, what one row is, what is missing by group, and how a value was measured.

The same habit carries over to AI tools: when an AI describes a chart, you check each claim against the real numbers.
