Write It Once

Terra Bean is a small coffee shop. Every month it gets a list of bean deliveries from its suppliers, the farms that sell it beans. Each list spells the same farm names differently: extra spaces, ALL CAPS, or nothing typed at all. Fixing the names by hand every month is slow, and each retyped fix comes out a little different.

1. The same fix, typed three times

In May, someone fixes the farm names by hand. In June, they copy the fix but forget to handle the empty cells. In July, they copy it again and change one method by mistake. Now there are three slightly different fixes for one job, and a report that groups deliveries by farm shows more farms than really exist.

You already know how to decide whether to drop, fill, or flag a gap, and how to write a function with def, parameters, and return. This reading puts the two together: one function that takes a messy column in and hands a clean column back.

3. What makes a function reusable

A value typed straight into a function's body, like one file name or one column name, is hardcoded. A function with a hardcoded column name only works on that one column, so next month someone copies it and edits it, and the drift starts again.

A reusable function has a clear function contract: what it takes in as parameters, and what it hands back with return. It should also avoid surprise side effects. A side effect is anything a function does besides returning a value, such as printing, changing a variable outside the function, or saving a file.

Terra Bean needs a function to clean name columns. Which design has the strongest contract for reuse?

4. Write the function

Here is a small delivery list. The same farm is typed three different ways, and one name is empty.

supplier_name,country,bags HILLTOP FARM ,colombia,12 hilltop farm,COLOMBIA ,8 Hilltop Farm,Colombia,10 sunrise beans, kenya,6 ,peru,4

New in this file:

  • .str.strip() removes spaces from the start and end of every value in a text column. .str.title() capitalizes the first letter of each word, so "hilltop farm" becomes "Hilltop Farm".
  • missing_label="Unknown" gives the parameter a default value. If a call leaves that argument out, Python uses "Unknown".
  • The text in triple quotes, right under the def line, is a docstring: a short note that explains the function's contract to anyone who uses it.

5. Call it again, and again

The pandas methods inside the function never change a column in place, which would mean editing the original. Each one is returning a copy: it leaves the original alone and hands back a new column. That's why clean_text_column needs its return line, and why the original column survives until you replace it.

Predict: clean_two_columns.py saves the raw country column as before, then cleans both columns. What does the last line, print(before[1]), show?

import pandas as pd def clean_text_column(raw_column, missing_label="Unknown"): """Take a column of text. Return a new column with extra spaces removed, each word capitalized, and empty cells set to missing_label.""" cleaned = raw_column.str.strip() cleaned = cleaned.str.title() cleaned = cleaned.fillna(missing_label) return cleaned deliveries = pd.read_csv("deliveries.csv") before = deliveries["country"] deliveries["supplier_name"] = clean_text_column(deliveries["supplier_name"], "Unknown Supplier") deliveries["country"] = clean_text_column(deliveries["country"], "Unknown Country") print(deliveries) print(before[1])
      supplier_name   country  bags
0      Hilltop Farm  Colombia    12
1      Hilltop Farm  Colombia     8
2      Hilltop Farm  Colombia    10
3     Sunrise Beans     Kenya     6
4  Unknown Supplier      Peru     4
COLOMBIA

Notice the two calls: the same function cleaned two columns, and each call passed its own label. Nothing inside the function changed.

Predict: next month, someone runs the function on names that are already clean. clean_twice.py cleans the column once, then cleans the result again. What do its two lines show?

import pandas as pd def clean_text_column(raw_column, missing_label="Unknown"): """Take a column of text. Return a new column with extra spaces removed, each word capitalized, and empty cells set to missing_label.""" cleaned = raw_column.str.strip() cleaned = cleaned.str.title() cleaned = cleaned.fillna(missing_label) return cleaned deliveries = pd.read_csv("deliveries.csv") once = clean_text_column(deliveries["supplier_name"]) twice = clean_text_column(once) print(once[0]) print(twice[0])
Hilltop Farm
Hilltop Farm

A function that changes nothing when you run it a second time is idempotent. That makes a cleaning function safe: running it on an already-clean file does no harm.

7. Wrap-up

  • A reusable cleaning function takes the column in as a parameter and hands a new column back with return.
  • The missing-value choice, like filling with "Unknown", lives inside the function, so it's made the same way every time.
  • A good cleaning function is idempotent: running it twice gives the same result as running it once.
