2. Stack two lists and find the repeats

Here are the two lists. In june.csv, D104 and D105 were sent again. The farm also corrected D105's count from 9 to 10.

delivery_id,supplier,country,bags D101,Hilltop Farm,Kenya,12 D102,Sunrise Beans,Colombia,8 D103,Blue Ridge Co-op,Peru,10 D104,Hilltop Farm,Kenya,6 D105,Sunrise Beans,Colombia,9
delivery_id,supplier,country,bags D104,Hilltop Farm,kenya ,6 D105,Sunrise Beans,Colombia,10 D106,Blue Ridge Co-op,PERU,TBD D107,Hilltop Farm, Kenya,11 D108,Sunrise Beans,colombia,7

Load both, and check the type of bags in each:

import pandas as pd
may = pd.read_csv("may.csv")
june = pd.read_csv("june.csv")
print(may["bags"].dtype)
print(june["bags"].dtype)
int64
str

One "TBD" makes pandas load the whole June bags column as text (str). Section 3 fixes that.

New in this cell: pd.concat([may, june], ignore_index=True) stacks the two tables, top to bottom. ignore_index=True numbers the rows 0 to 9 again, so no row label shows up twice.

both = pd.concat([may, june], ignore_index=True)
print(len(may), len(june), len(both))
5 5 10

D104 and D105 are now duplicate rows: the same deliveries, twice. If we leave them in, every total counts them twice. delivery_id is the key column, because each ID names one delivery.

Predict: .duplicated() with no subset= only counts rows that match in every column. What does cell [3] print?

print(both.duplicated().sum())
print(both.duplicated(subset="delivery_id").sum())
0
2

Match repeats on the key, not the whole row. A record that is sent again can come back with a changed field, like a new spelling or a corrected count. both.drop_duplicates(subset="delivery_id") removes the repeats and keeps the first copy of each ID.

3. Turn text into numbers

pd.to_numeric turns a column of text into numbers. On June's bags, it stops at "TBD":

pd.to_numeric(june["bags"])
ValueError: Unable to parse string 'TBD' at position 2

Adding errors="coerce" tells pandas to coerce: every value that can't become a number becomes NaN.

Predict: how many NaN values does cell [5] count?

bags = pd.to_numeric(june["bags"], errors="coerce")
bags.isna().sum()
np.int64(1)

Coerce does not fix "TBD". It turns it into a new missing value, so count the NaN values right after you coerce. That count feeds your drop, fill or flag decision. Watch out: .mean() skips NaN without any warning, so an average can quietly leave out a delivery.

5. Put every fix in one function

You could paste these fixes into a new cell each month. But if you later change a fix, you have to change it in every copy, and it is easy to miss one. A function keeps each fix in one place. Small one-job functions are easy to test, and one function can call another.

def to_number(series):
    return pd.to_numeric(series, errors="coerce")

def tidy_text(series):
    return series.str.strip().str.lower()

def clean_deliveries(df):
    df = df.drop_duplicates(subset="delivery_id")
    df["bags"] = to_number(df["bags"])
    df["country"] = tidy_text(df["country"])
    return df

The first line of clean_deliveries matters. df.drop_duplicates(...) makes a new table, and df = points the name at it. Every line after that works on the new table, so the table you handed in stays as it was. If the function skipped that step and set a column on df right away, your original table would change too. pandas 3 does not stop that.

A reusable function is one you call on two or more different inputs. Cell [9] calls clean_deliveries on the stacked table and on June alone.

New in this cell: assert stops the notebook with an error if its condition is False. Here it checks that no delivery ID repeats.

Predict: what does cell [9] print?

clean_both = clean_deliveries(both)
clean_june = clean_deliveries(june)
assert clean_both["delivery_id"].duplicated().sum() == 0
print(len(clean_both), len(clean_june))

june still holds text, and clean_june holds numbers. The first line did its job.

7. Wrap-up

  • Stack lists with pd.concat(..., ignore_index=True), then find and remove repeats on the key column with subset=.
  • Use pd.to_numeric(..., errors="coerce") for numbers stored as text, then count the new NaN values. Use .str.strip().str.lower() for labels, and check .value_counts() before and after.
  • Put the fixes in a function whose first line makes a new table, and prove it is reusable by calling it on a second, different input.

New situation: July's list arrives. It repeats one June delivery, says "TBD" for two counts, and has " Peru" with a space. What should you do?

In interviews, "When should repeated code become a function?" is a common question. A good answer: at the second real repeat, or right away when the same cleaning runs on every new file.

A clean table is where the analysis starts. Next you can group it and look for patterns you can trust.
