Beneath the Total

Starlight Cinema is a neighborhood movie theater. The manager hands you a month of snack-bar orders and asks, "What's going on with snack sales?" You could answer with the total. It's true, but it doesn't tell the manager anything new. This reading is about finding a pattern that does.

1. A total versus a finding

You already know how to group rows and work out a mean or a count for each group. This reading adds no new syntax. It's about judgment: which groups to compare, and when a difference is worth telling someone.

The file orders.csv has 240 rows, one per snack order, with four columns:

  • show_time: matinee (an afternoon show) or evening
  • bought_online: True if the movie ticket was bought online, False if it was bought at the counter
  • tickets: how many movie tickets came with the order
  • snack_dollars: how much the order spent on snacks

How the examples work: each example is a .py file that reads orders.csv. The Run button shows what the file prints. On your own laptop, you'd type python3 name.py in the terminal.

3. What a total can and can't tell you

Predict: total.py prints the total snack sales and the average per order. What can those two numbers tell the manager?

import pandas as pd orders = pd.read_csv("orders.csv") print(orders["snack_dollars"].sum().round(2)) print(orders["snack_dollars"].mean().round(2))
3120.0
13.0

$3,120 and $13 per order are true. But one number describes the whole month at once, so it can't show how one part of the data differs from another. A true statement that compares nothing is a surface-level restatement. So is a known fact: something the manager already believes, like "popcorn is our best seller." It can be accurate and still not be news.

4. Split the data and compare

To find a pattern, split the rows into a segment, a group of rows that share a category, and measure it against a comparison group, the rows you compare it to. Matinee orders against evening orders is one segment to try. by_show.py asks for the count and the mean of each group at once.

Predict: which group spends more on snacks per order?

import pandas as pd orders = pd.read_csv("orders.csv") print(orders.groupby("show_time")["snack_dollars"].agg(["count", "mean"]))
           count  mean
show_time
evening      144  10.0
matinee       96  17.5

Matinee orders spend $17.50 on average, which is 75% more than the $10.00 for evening orders. That is a non-obvious pattern: a real difference between groups, big enough to matter, that the manager didn't already expect. The manager could act on it, for example by opening a second snack line before afternoon shows.

The same output shows 144 evening orders and 96 matinee orders. On its own, is "we had more evening orders" a non-obvious pattern?

5. Check that enough rows stand behind it

A difference only counts once it rests on a reliable slice: enough rows that the number would likely look similar if you collected the data again. The matinee number comes from 96 orders, which is plenty. Two or three orders can look just as dramatic by luck.

The 3 orders from the late-night horror marathon averaged $31 on snacks. Should you tell the manager that marathon crowds spend the most?

7. Wrap-up

  • A total or a known fact is true but compares nothing, so it isn't a finding.
  • A pattern comes from splitting the rows into a segment and a comparison group, and finding a real difference.
  • Check the count behind each number before you repeat it.

New situation: the manager now asks about movie tickets, not snacks. Which statement is a non-obvious pattern?

In interviews: "Tell me about an interesting finding in a dataset" is a common question. A strong answer names the segment, the comparison group, the size of the gap, and how many rows stood behind it.

Where this goes next: once you find a pattern, the next step is questioning the data under it: where it came from and what it might be missing.
