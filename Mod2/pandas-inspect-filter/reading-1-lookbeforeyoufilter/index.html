Look Before You Filter

A food bank collects donated food and gives it to families. Each time someone drops off food, a volunteer adds one row to a file: who gave it, what kind of food, how much it weighed, and which site got it. Before anyone counts anything, someone should look closely at that file.

1. The food bank's file

Here are six rows of the food bank's file. It is a CSV file, which means "comma-separated values": each line is one row, and commas split the columns. One drop-off was never weighed, so its weight is empty.

donor_type,category,weight_lbs,site Family,Produce,12,Downtown Company,Canned,85,Eastside Grocery,Dairy,,Downtown Family,Bread,8,Westside Company,Produce,63,Eastside Grocery,Frozen,51,Downtown

If no one checks the file first, that empty weight slips into every total, and the food bank reports numbers that are quietly wrong. You already know Python lists, comparisons, and classes. In this reading, you load a file into a table, check what's in it, and keep only the rows you need.

How the examples work: each example is a .py file that sits in the same folder as intake.csv. The Run button shows what the file prints. On your own laptop, you'd type python3 name.py in the terminal.

3. Load the file into a DataFrame

pandas is a Python library for working with tables. A library is code someone else wrote that you can load into your file. pandas reads a CSV file and hands back a DataFrame: a table with rows and named columns, stored as one Python object.

New in this file: import pandas as pd loads pandas and gives it the short name pd. pd.read_csv("intake.csv") reads the file and returns a DataFrame. Printing a DataFrame shows it as a table, with a row number, called the index, on the left.

Predict: the Dairy row has an empty weight in intake.csv. What does pandas show in that cell?

import pandas as pd intake = pd.read_csv("intake.csv") print(intake)
  donor_type category  weight_lbs      site
0     Family  Produce        12.0  Downtown
1    Company   Canned        85.0  Eastside
2    Grocery    Dairy         NaN  Downtown
3     Family    Bread         8.0  Westside
4    Company  Produce        63.0  Eastside
5    Grocery   Frozen        51.0  Downtown

NaN ("not a number") is how pandas marks a missing value. Notice the other weights changed too: 12 became 12.0. A column with a missing value holds decimal numbers in pandas, so every weight gets a .0.

4. Look before you trust it

A DataFrame is an object, so it has attributes and methods, just like the classes you've built. Three of them answer the first questions you ask about any new table.

  • intake.shape is an attribute, a stored fact, so it has no parentheses. It gives (rows, columns).
  • intake.head() is a method, an action, so it needs parentheses. It returns the first 5 rows, which is handy when a file has thousands.
  • intake.info() is a method that prints a summary of every column: how many values are not missing ("non-null"), and the column's dtype, the type of data pandas stored. object means text, int64 means whole numbers, and float64 means decimal numbers.

Predict: in the output of intake.info(), how many non-null values will weight_lbs have?

import pandas as pd intake = pd.read_csv("intake.csv") print(intake.shape) intake.info()
(6, 4)
<class 'pandas.core.frame.DataFrame'>
RangeIndex: 6 entries, 0 to 5
Data columns (total 4 columns):
 #   Column      Non-Null Count  Dtype
---  ------      --------------  -----
 0   donor_type  6 non-null      object
 1   category    6 non-null      object
 2   weight_lbs  5 non-null      float64
 3   site        6 non-null      object
dtypes: float64(1), object(3)
memory usage: 324.0+ bytes

intake.info() prints its summary by itself, so the file doesn't wrap it in print(). The line for weight_lbs is the one to catch: 5 of 6 rows have a weight. Now the food bank can decide what to do about the missing one, before it changes any totals.

5. Keep only the rows you need

Put a column name in square brackets, intake["weight_lbs"], and you get that one column. One column on its own is called a Series. Compare a Series to a number, and pandas runs the comparison once for every row. The result is a boolean mask: one True or False per row.

Predict: how many True values does heavy_mask.py print?

import pandas as pd intake = pd.read_csv("intake.csv") heavy = intake["weight_lbs"] > 50 print(heavy)
0    False
1     True
2    False
3    False
4     True
5     True
Name: weight_lbs, dtype: bool

Row 2 is the missing weight. Comparing NaN to a number gives False, with no error and no warning. A filter on that column quietly drops the row.

To filter, put the mask inside square brackets after the DataFrame: intake[mask]. pandas keeps the rows marked True and drops the rest. Using a True/False condition this way is called a boolean filter.

Fill in the blank: keep the heavy drop-offs

import pandas as pd intake = pd.read_csv("intake.csv") heavy = intake["weight_lbs"] > 50 print(intake[____])

  2. Type only that name, with no brackets and no quotes. (Typing the full condition, intake["weight_lbs"] > 50, also works.)
  3. Press Check. You get 2 tries. Why: the brackets need a True/False value for each row, and that variable holds one.

6. Two conditions, and one column

To require two conditions, join them with &, which means "and" in a pandas filter. Wrap each condition in its own parentheses. (Python's plain and works on one True or False at a time, so it fails on a whole column.)

Predict: how many rows does heavy_produce.py print?

import pandas as pd intake = pd.read_csv("intake.csv") both = intake[(intake["weight_lbs"] > 50) & (intake["category"] == "Produce")] print(both)
  donor_type category  weight_lbs      site
4    Company  Produce        63.0  Eastside

Sometimes you want one column from the filtered rows, not every column. .loc[] takes the mask and a column name in one step: intake.loc[mask, "column"].

Predict: what does heavy_donors.py print?

import pandas as pd intake = pd.read_csv("intake.csv") print(intake.loc[intake["weight_lbs"] > 50, "donor_type"])
1    Company
4    Company
5    Grocery
Name: donor_type, dtype: object

A volunteer writes intake[intake["weight_lbs"] > 50 and intake["site"] == "Downtown"] and gets ValueError: The truth value of a Series is ambiguous. What is the fix?

8. Wrap-up

  • pd.read_csv() loads a file into a DataFrame. Check it with .shape, .head(), and .info() before you trust it.
  • A comparison on a column makes a boolean mask. df[mask] keeps only the True rows.
  • Join two conditions with & and parentheses. Use .loc[mask, "column"] to get one column of the matching rows.
