Look Before You Filter

A food bank weighs every donation and adds one row to a file: who gave it, what kind of food, the weight, and which site got it. The manager asks, "How much produce came into Eastside?" One line of code can answer. But a blank weight or a row typed twice makes that answer wrong.

2. From a .py file to a notebook

A .py file runs every line from top to bottom, then forgets everything. A notebook (a .ipynb file) splits code into cells. You run one cell at a time with Shift+Enter. The kernel keeps your variables in memory, so a later cell can use a name an earlier cell made. A cell also shows its last line's value without print(). Notebooks are for exploring, and finished programs are still .py files. When you share your analysis, though, the notebook is often what you hand over, so tidy it up for someone else to read.

Here is the food bank's file, intake.csv:

donor_type,category,weight_lbs,site Family,Produce,12,Eastside Grocery,Canned,40,Downtown Company,Produce,25,Eastside Family,Dairy,,Westside Grocery,Produce,18,Downtown Family,Bread,6,Eastside Company,Produce,30,Westside Grocery,Canned,40,Downtown

New in this cell: import pandas as pd loads pandas. pd.read_csv("intake.csv") reads the file into a DataFrame, pandas' table object, here named df. df.shape gives a pair of numbers: rows first, then columns. It has no parentheses because it is a stored fact, not an action.

Predict: what does cell [1] show?

import pandas as pd
df = pd.read_csv("intake.csv")
df.shape
(8, 4)

The order you run cells in, not the order on the page, decides what the kernel knows.

Predict: what happens when cell [1] of new_notebook.ipynb runs in a fresh kernel?

df.shape
NameError: name 'df' is not defined

The reverse problem hides better. Delete the read_csv cell after running it, and df still lives in the kernel, so the notebook seems fine. Restart & Run All restarts the kernel and runs every cell from the top. Do it before you share a notebook.

3. Four checks before you trust a file

Run four checks on every new file: shape (did every row arrive?), dtypes, missing values, and duplicates. Shape is done. Next is the dtype, the type pandas gave each column.

Predict: which dtype will weight_lbs get? Every weight in the file is a whole number, but one is blank.

df.dtypes
donor_type        str
category          str
weight_lbs    float64
site              str
dtype: object

pandas stores a missing number as NaN ("not a number"), and NaN is a decimal number. So one blank turns the whole column into float64. Text columns show str. Older tutorials and AI answers say object, the old label for text. If a column of numbers shows str, something in it isn't a clean number, like "12 lbs".

.isna() marks each missing cell True. .sum() then adds them up per column, because True counts as 1.

df.isna().sum()
donor_type    0
category      0
weight_lbs    1
site          0
dtype: int64

.duplicated() marks a row True when it matches an earlier row exactly, in every column. A donation logged twice adds its weight twice.

  1. Look back at intake.csv and find any row that matches an earlier row in all four columns.
  2. Type how many rows df.duplicated() will mark True. Type only a number.
  3. Press Check, then run cell [4].

Why: counting repeats before you add anything up keeps totals honest.

df.duplicated().sum()
np.int64(1)

A count can show as np.int64(...). That is just a whole number, stored the NumPy way. Write down what each check found, and fix problems later. If a check finds zero problems, that is still a finding: you know the file is sound instead of hoping it is.

4. Keep only the rows you need

A boolean filter works in two steps. First, a comparison makes a column of True/False, one per row:

df["site"] == "Eastside"
0     True
1    False
2     True
3    False
4    False
5     True
6    False
7    False
Name: site, dtype: bool

Then df[...] keeps only the rows marked True. The result is a new, smaller DataFrame. df itself still has 8 rows.

eastside = df[df["site"] == "Eastside"]
len(eastside)
3

The manager asked about produce at Eastside, so you need two conditions at once. Python's word and works on one True or False. A filter compares whole columns, row by row, so pandas joins conditions with the symbol &, which means AND. Each condition goes inside its own parentheses.

  1. Look back at intake.csv. Count the rows where the site is Eastside and the category is Produce.
  2. Type how many rows cell [7] will keep. Type only a number.
  3. Press Check, then run cell [7].

Why: guessing the count first lets you tell if a filter did what you meant.

eastside_produce = df[
    (df["site"] == "Eastside")
    & (df["category"] == "Produce")
]
len(eastside_produce)
2

& narrows: 2 rows is fewer than the 3 Eastside rows or the 4 Produce rows. Its partner | means OR, which keeps a row if either condition is True, so it widens the result.

Predict: cell [8] is the same filter without the parentheses. What happens?

df[df["site"] == "Eastside" & df["category"] == "Produce"]
TypeError: unsupported operand type(s) for &: 'str' and 'StringArray'

Filtering picks rows. Sorting ranks them. sort_values(..., ascending=False) puts the biggest first. Double brackets, [["category", "weight_lbs"]], pick a list of columns, and .head(3) keeps the top 3 rows.

heaviest = df.sort_values("weight_lbs", ascending=False)
heaviest[["category", "weight_lbs"]].head(3)
  category  weight_lbs
1   Canned        40.0
7   Canned        40.0
6  Produce        30.0

Rows 1 and 7 are the donation logged twice, taking two of the top three spots. Count duplicates before you rank or total anything.

6. Wrap-up

  • A notebook runs one cell at a time. The kernel remembers what you ran, in the order you ran it. Restart & Run All before you share.
  • Check every new file four ways: shape, dtypes, missing values, duplicates. Zero problems is still a finding.
  • A boolean filter keeps the rows where a condition is True. Join conditions with &, each one in its own parentheses.

New situation: next month, the Westside site sends its own intake file. The manager wants the total pounds of dairy that came into Westside. What do you do first?

In interviews, "How do you filter a DataFrame on two conditions?" is a common question. A good answer names &, the parentheses, and why they are needed.
