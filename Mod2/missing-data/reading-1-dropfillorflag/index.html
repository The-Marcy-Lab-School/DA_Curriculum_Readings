Drop, Fill, or Flag

Paws & Go is a dog-walking app. Each row in its log is one walk: who walked the dog, for how many minutes and miles, and how big the dog was. Some cells are empty. Each empty cell needs one of three choices: drop, fill, or flag. The wrong choice can quietly change every number in a report.

3. Find the gaps, then drop what's empty

Here is a small piece of the walk log. Two rows came back completely empty when the app crashed while saving.

walker,minutes,miles,dog_size Sam,30,1.2,small Lee,45,1.8,large ,,, Kai,30,,medium Ana,60,2.5, Sam,20,0.8,small ,,, Lee,40,1.6,

An empty cell is a missing value. Pandas shows it as NaN, short for "Not a Number." Pandas uses NaN for any empty cell, even in a text column.

Predict: count_gaps.py prints one count per column. What count does it print for dog_size?

import pandas as pd walks = pd.read_csv("walks.csv") print(walks.isna().sum())
walker      2
minutes     2
miles       3
dog_size    4
dtype: int64

The two crashed rows have nothing real in them. When a row has nothing left to use, you drop it: you remove it from the DataFrame. .dropna(how="all") drops only the rows where every cell is empty, so a row with just one gap stays.

4. Fill a gap with a typical value

Kai's walk is missing its miles because Kai's phone lost signal. The rest of the row is real: a real walk, a real 30 minutes, a real dog. Dropping the row would throw that away. Instead, you can fill the gap with a typical value. Filling a gap with a value you work out from the column is called imputation. For a number column without extreme values, the median is a fair choice. .fillna(value) puts value into every empty cell of a column.

New in this file: .median() gives a column's median, the same way .mean() gives its mean. Pandas skips empty cells when it works it out.

Predict: what number does fill_miles.py put in Kai's miles cell?

import pandas as pd walks = pd.read_csv("walks.csv") walks = walks.dropna(how="all") typical_miles = walks["miles"].median() walks["miles"] = walks["miles"].fillna(typical_miles) print(walks)

5. Flag a gap you shouldn't guess

Most of the empty dog_size cells come from walks booked by phone. The person taking the call often skips that question. So the gaps follow a pattern. If you filled them with the mode, "small," every phone booking would look like a small dog, and a report on dog sizes would be wrong.

So you flag the gap instead. First, build a flag column: a new True/False column made with .isna() that remembers which rows were empty. Then fill the gap with a sentinel value, a placeholder like "unknown" that clearly means "not recorded" and is not a real answer.

New in this file: walks[["walker", "dog_size", "size_missing"]] uses two sets of square brackets to pick several columns, so the output stays short.

Predict: in flag_size.py, what does size_missing show in Ana's row?

import pandas as pd walks = pd.read_csv("walks.csv") walks = walks.dropna(how="all") walks["size_missing"] = walks["dog_size"].isna() walks["dog_size"] = walks["dog_size"].fillna("unknown") print(walks[["walker", "dog_size", "size_missing"]])
  walker dog_size  size_missing
0    Sam    small         False
1    Lee    large         False
3    Kai   medium         False
4    Ana  unknown          True
5    Sam    small         False
7    Lee  unknown          True

Predict: flag_too_late.py swaps the two middle lines, so the fill runs first. What does size_missing show in Ana's row now?

import pandas as pd walks = pd.read_csv("walks.csv") walks = walks.dropna(how="all") walks["dog_size"] = walks["dog_size"].fillna("unknown") walks["size_missing"] = walks["dog_size"].isna() print(walks[["walker", "dog_size", "size_missing"]])
  walker dog_size  size_missing
0    Sam    small         False
1    Lee    large         False
3    Kai   medium         False
4    Ana  unknown         False
5    Sam    small         False
7    Lee  unknown         False

The rule: build the flag column before you fill. Once .fillna() runs, no cell is empty anymore, so .isna() has nothing left to find.

7. Wrap-up

  • Drop a row when nothing in it is usable, like the two crashed rows.
  • Fill a small gap with a typical value when the rest of the row is real, like Kai's miles.
  • Flag a gap that follows a pattern, and build the flag column before you fill.

New situation: Paws & Go adds a star rating that owners can give after a walk. Giving one is optional, and about half of the walks have no rating. A report will show each walker's average rating. What fits best?
