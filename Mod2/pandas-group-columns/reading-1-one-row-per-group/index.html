One Row Per Group

A blood drive is an event where people come to give blood. A nonprofit runs drives at a library, a community center, and a fire station. It writes one row per drive. After a while, it has a pile of rows and one question: which place is worth going back to?

Data Mining — digging into a real dataset to surface a genuinely non-obvious relationship or finding, not just restating what's already visible on the surface. Grouping rows and deriving new columns are the two mechanical moves that make that kind of digging possible in the first place.

1. Six drives, three places

Here is the nonprofit's file. Each row is one drive: the place, how many donors signed up, how many units of blood it collected (a unit is one bag, from one donor), and how many hours volunteers worked.

site,donors,units,volunteer_hours Library,34,30,6 Community Center,22,20,5 Fire Station,55,50,10 Library,44,40,8 Community Center,28,25,5 Community Center,33,30,6

The rows for each place are mixed together. Adding them up by hand works for six rows, but it falls apart at six hundred, and one missed row gives the wrong place the credit. You already know how to load a file with pandas and filter its rows. In this reading, you turn many rows into one summary row per place, and you build a new column instead of working out the same math by hand.

3. One row per group with groupby

groupby is a DataFrame method that splits rows into groups by a category, then applies a summary to each group separately. The column you group by is the group key. Here it is "site", so every row with the same place lands in the same group. The summary, like a total or a mean, is an aggregation: many values reduced to one number per group.

pandas calls this split-apply-combine: split the rows into groups, apply the summary inside each group, then combine the results into one row per group. The line reads left to right: group by "site", pick the "units" column, then take the .sum().

Predict: what total does site_totals.py show for Community Center?

import pandas as pd drives = pd.read_csv("drives.csv") totals = drives.groupby("site")["units"].sum() print(totals)
site
Community Center    75
Fire Station        50
Library             70
Name: units, dtype: int64

Six rows became three: one per place, sorted by name. The original drives DataFrame did not change.

Fill in the blank: the mean per place

4. Several summaries at once with .agg()

.agg() takes a list of summary names and works out every one of them, per group, in one line. You don't need to repeat groupby three times.

Predict: in site_summary.py, what is the count for Fire Station?

import pandas as pd drives = pd.read_csv("drives.csv") summary = drives.groupby("site")["units"].agg(["count", "mean", "sum"]) print(summary)
                  count  mean  sum
site
Community Center      3  25.0   75
Fire Station          1  50.0   50
Library               2  35.0   70

Look at Fire Station: it has the biggest mean, 50 units, but it is based on a single drive. The count column tells you how much to trust each mean.

5. Build a new column

Totals show how much each place collected. They don't show how much volunteer time it took. For that, the nonprofit needs units per volunteer hour, a column the file doesn't have. A derived column is a new column worked out from columns you already have. pandas runs the math on every row at once, with no loop.

New in this file: drives["units_per_hour"] = ... creates a column with that name. drives[["site", "units_per_hour"]] uses a list of names inside the brackets to pick two columns.

Predict: row 1 had 20 units and 5 volunteer hours. What does add_rate.py show for row 1?

import pandas as pd drives = pd.read_csv("drives.csv") drives["units_per_hour"] = drives["units"] / drives["volunteer_hours"] print(drives[["site", "units_per_hour"]])
               site  units_per_hour
0           Library             5.0
1  Community Center             4.0
2      Fire Station             5.0
3           Library             5.0
4  Community Center             5.0
5  Community Center             5.0

You want a new column, units_per_donor: units divided by donors. Which line creates it?

Group the new column

Now combine both moves: build the column, then group by place and take the mean of it.

Predict: which place will site_rates.py show with the lowest units per hour?

import pandas as pd drives = pd.read_csv("drives.csv") drives["units_per_hour"] = drives["units"] / drives["volunteer_hours"] rates = drives.groupby("site")["units_per_hour"].mean() print(rates)
site
Community Center    4.666667
Fire Station        5.000000
Library             5.000000
Name: units_per_hour, dtype: float64

Community Center collected the most blood in total, 75 units. Per volunteer hour, it ranks last, because one drive took 5 hours for only 20 units. The total alone hid that.

7. Wrap-up

  • df.groupby("key")["column"].sum() splits rows by the key, sums each group, and gives one row per group.
  • .agg(["count", "mean", "sum"]) gives several summaries per group at once. Check the count before you trust a mean.
  • df["new"] = df["a"] / df["b"] builds a derived column for every row at once, and you can group by it like any other column.
