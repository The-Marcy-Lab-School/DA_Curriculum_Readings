Two Questions, Two Tests

Rise & Shine Bakehouse hung a new menu board in three of its six shops for one month. The owner has two questions about the receipts: did people spend more, and did people order different things? Those two questions need two different statistical tests.

1. One month of receipts, two questions

A menu board is the big sign above the counter that lists everything for sale. Three shops kept the old board, Layout A. Three hung a new board, Layout B, which groups items by meal. After a month, the owner has 985 receipts.

If you pick the wrong test, Python still prints a normal-looking p-value, and nothing warns you. You already know what a null hypothesis, a p-value and a confidence interval mean. This reading runs both tests in Python and reads what comes back.

3. A number or a label?

load_orders.py loads the receipts and shows the first four rows:

import pandas as pd orders = pd.read_csv("bakehouse_orders.csv") print(orders.shape) print(orders.head(4))
(985, 3)

0      B         7.33     pastry
1      A        10.24   sandwich
2      B         9.46     pastry
3      B        14.88   sandwich

(985, 3) means 985 rows and 3 columns, which matches the 985 receipts. Check this every time before a test runs, because a test can't tell you that half your data failed to load. (The 0 to 3 on the left are row numbers that pandas adds.)

Look at the last two columns. order_total holds a continuous variable: a measurement on a scale, a number you can average. order_type holds a categorical variable: its values are labels or groups, and you can't average "pastry." That difference picks the test:

  1. To compare the average of a number between two groups, run a t-test. Here: is the average order_total different under Layout A and Layout B?
  2. To check whether two labels are related, run a chi-square test. Here: is order_type related to layout?

Practice the choice on three new questions. Ask first: is the outcome a number you could average, or a label you could only count?

Question A: is the average tip, in dollars, different at the new-board shops than at the old-board shops?

Question B: is payment method (cash, card, or app) related to which board a shop hung?

Question C: does the average order total differ across the chain's three neighborhoods: Downtown, Riverside, and Eastside?

Need a hint?

Order total is a number. Now count the groups, and remember that a t-test compares two groups.

4. Question 1: did the average order total change?

Write the null hypothesis first, before any code runs: the average order total is the same under both layouts, and the gap in this month's receipts is ordinary random variation.

New in this file: SciPy is a free Python library of science and statistics tools. from scipy import stats loads its statistics part. stats.ttest_ind(a, b) runs a t-test on two separate groups ("ind" means independent: different people in each group). It works with a minus b. Its result has a .pvalue, and .confidence_interval() gives the 95% range, with ends .low and .high.

Predict: the file works with Layout A minus Layout B. Layout A averaged $9.42 and Layout B averaged $10.01. Will the middle of the confidence interval that ttest_layouts.py prints be positive or negative?

import pandas as pd from scipy import stats orders = pd.read_csv("bakehouse_orders.csv") layout_a = orders[orders["layout"] == "A"]["order_total"] layout_b = orders[orders["layout"] == "B"]["order_total"] print("Layout A mean:", round(layout_a.mean(), 2)) print("Layout B mean:", round(layout_b.mean(), 2)) result = stats.ttest_ind(layout_a, layout_b) ci = result.confidence_interval(confidence_level=0.95) print("p-value:", round(result.pvalue, 2)) print("95% CI:", round(ci.low, 2), "to", round(ci.high, 2))
Layout A mean: 9.42
Layout B mean: 10.01
p-value: 0.03
95% CI: -1.12 to -0.06

The p-value is 0.03. If the two boards really had the same average order, a gap this big would show up about 3 times in 100 by chance. That is below the usual 0.05 cutoff.

The whole interval is below zero, so the data does not fit "no difference." But it runs from $1.12 to $0.06. Layout B's real gain per order could be about a dollar, or about six cents. The p-value alone would never tell you that.

Given a 95% confidence interval of −$1.12 to −$0.06 (A minus B), which sentence is the honest one to bring the owner?

5. Question 2: did the mix of orders change?

The null hypothesis, written first again: the two layouts produce the same mix of drink-only, pastry, and sandwich orders, and any difference in the counts is random variation.

A chi-square test needs a contingency table first: a table of counts crossing two categories, with one category down the rows and the other across the columns. The test also uses degrees of freedom, a number tied to how many counts in the table are free to change once the row and column totals are set. For a table like this one, it is (rows − 1) × (columns − 1).

New in this file: pd.crosstab(rows, columns) builds a contingency table. stats.chi2_contingency(table) returns four values, which fill the four names left of = in order: the test statistic, the p-value, the degrees of freedom, and the expected counts, the table you would see if the two labels were unrelated.

Predict: the table will have 2 rows (A and B) and 3 columns (drink-only, pastry, sandwich). What will order_mix.py print for degrees of freedom?

import pandas as pd from scipy import stats orders = pd.read_csv("bakehouse_orders.csv") table = pd.crosstab(orders["layout"], orders["order_type"]) print(table) chi2, p, dof, expected = stats.chi2_contingency(table) print("p-value:", round(p, 2)) print("degrees of freedom:", dof) print("expected counts:") print(expected.round(1))
order_type  drink-only  pastry  sandwich
layout
A                  115     210       155
B                   97     199       209
p-value: 0.01
degrees of freedom: 2
expected counts:
[[103.3 199.3 177.4]
 [108.7 209.7 186.6]]

Compare the real counts with the expected ones. If layout had nothing to do with order type, Layout B would have had about 187 sandwich orders. It had 209. The p-value of 0.01 says a gap this large would show up about 1 time in 100 if the mix were really the same.

A chi-square test shows that two labels are related, an association. It does not show the board caused the change. Something else could have changed at the same time, like the three Layout B shops being closer to offices.

Check before you trust it. Each test assumes something about the data, and SciPy does not check for you. A t-test assumes each group is roughly bell-shaped with no wild outliers. A chi-square test assumes every expected count is at least about 5. Here the smallest is 103.3, so that check passes. If an assumption fails, SciPy still prints a normal-looking p-value.

The chi-square p-value is 0.01. What has the owner learned?

8. Wrap-up

  • The kind of data picks the test: a number you can average points to a t-test, and two labels point to a chi-square test on a contingency table.
  • Read the p-value and the confidence interval together: one says whether chance is a believable explanation, the other says how big the difference could be.
  • A chi-square test shows association, not cause, and neither test checks its own assumptions.

New situation: the owner also wants to know whether the share of customers who joined the loyalty card (yes or no) differs between Layout A and Layout B shops. Which test fits, and what is the null hypothesis?

In interviews: "How do you choose between a t-test and a chi-square test?" comes up often, and the strong answer starts with the data type of the outcome.

Where this goes next: a significant result says a gap is probably real, so the next question is whether it is big enough to act on.
