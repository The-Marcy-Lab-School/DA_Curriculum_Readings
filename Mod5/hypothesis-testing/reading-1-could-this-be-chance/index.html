Could This Just Be Chance?

Bridgeway, a free job-training center, taught two versions of its resume class. Graduates of version B got more callbacks. Before Bridgeway pays to run version B everywhere, it has to answer one question: did version B really work better, or did the gap show up by chance?

1. One class, two versions, one gap

Half of Bridgeway's students took the usual class, version A. The other half took version B, which adds a practice round where a volunteer reads each resume and says what stood out. Six months later, staff counted callbacks: an employer calling or emailing back, usually to set up an interview.

  1. Version A: 120 graduates. 42 got a callback. That is 35.0%.
  2. Version B: 118 graduates. 52 got a callback. That is 44.1%.

Version B is ahead by 9.1 percentage points. That is plain subtraction of one percentage from the other: 44.1 minus 35.0.

Version B costs more to run, so a wrong answer either wastes money or drops a class that helps people. You already know how to compute a percentage and compare two groups. This reading adds the next step: deciding whether a gap is strong enough to act on.

3. Two explanations for the same gap

Picture a jar of mixed blue and white marbles. Scoop it into two smaller jars at random and count the blue in each. The two counts will not match, even though both jars came from the same place. Random splits always make small gaps.

The 238 graduates are a sample: the people Bridgeway actually measured, not everyone it will ever teach. So the 9.1-point gap has two possible explanations:

  1. Version B really is better. The practice round helps people get callbacks.
  2. It's the marble jar. Both versions work the same, and these 238 people happened to split with a few more callbacks on the B side.

A hypothesis test gives explanation 2 a name and takes it seriously first.

The null hypothesis is the claim that there is no real difference, and any gap in the data is ordinary random variation.

The alternative hypothesis is the claim that a real difference exists.

Write both down before you see any result. A hypothesis written afterward can be bent to fit what you saw. Also, a test only ever pushes on the null. It can find strong evidence against the null, or fail to. It can never prove the null true.

Which of these is a correctly stated null hypothesis for the Bridgeway comparison?

4. What the p-value says

Bridgeway's test returned a p-value of 0.15. A p-value answers this question: if there were really no difference, how often would a gap at least this big show up just by chance?

If the two versions really worked equally well, a gap of 9.1 points or more would turn up about 15 times in 100, just from who ended up in which group.

Notice that the sentence starts with "if." A p-value is always computed by first assuming the null is true.

Two common misreadings. "There is a 15% chance the null is true" is wrong, because the math assumed the null was true to get 0.15. "There is a 15% chance this result was a fluke" is wrong for the same reason. Both put a probability on your conclusion, and a p-value only describes the data.

Most teams use 0.05 as their cutoff. A p-value below 0.05 is called statistical significance: chance is a poor explanation for the gap. It says nothing about whether the gap is big. At 0.15, Bridgeway's result is not significant. The honest sentence is: "This data does not give strong evidence that version B works better." It does not say version B is useless.

The p-value is 0.15. Which sentence states what it measures?

A board member says, "Great, so we have shown the practice round makes no difference." What is wrong with that?

5. The confidence interval: how big could the gap be?

A p-value says whether chance is a believable explanation. It says nothing about size. For size, use a confidence interval: a range of values for the real difference that the data is consistent with.

Bridgeway's 95% confidence interval runs from −3.3 to +21.4 percentage points, with 9.1 as the best single estimate. The top end says version B might help a lot. The bottom end is negative, so version B might even be a little worse. Zero, meaning "no difference," sits inside the range.

Rule: if the confidence interval for a difference includes zero, the result is not convincing. A 95% interval that includes zero and a p-value above 0.05 tell you the same thing.

Given a 95% confidence interval from −3.3 to +21.4 percentage points, which sentence is the honest one to bring the board?

6. Two ways to be wrong

Whatever Bridgeway decides, it could be wrong in one of two ways.

  1. A Type I error is a false alarm: you call a difference real when nothing was there. Bridgeway pays for version B everywhere, and callbacks never go up.
  2. A Type II error is a miss: a real difference was there, and the study did not catch it. Bridgeway drops version B, and a class that would have helped people get interviews is gone.

Pushing down one error tends to push up the other. Demand very strong evidence and you miss more real effects. Accept weak evidence and you get more false alarms. Choosing 0.05 as the cutoff sets how much false-alarm risk you accept.

Bridgeway drops version B because the result was not significant. A later, bigger study shows version B really did raise callbacks. Which error did Bridgeway make the first time?

7. Sample size: too small, and too big

With about 120 people in each group, Bridgeway's study could only reliably catch a gap of about 17 percentage points or more. That number is the study's minimum detectable effect: the smallest difference a study is big enough to reliably catch. The gap Bridgeway hoped for was 9 points, well under 17. So the study was likely to come back unclear no matter what was true. Reliably catching a 9-point gap would take about 460 graduates in each group.

The rule: a smaller difference needs a bigger sample. So "how many people do we need?" only has an answer once someone says how small a difference would still be worth acting on.

Bridgeway wants to test a small change it expects to raise callbacks by about 3 percentage points, using 60 people in each group. What is the real risk?

When a huge sample makes a tiny gap significant

Now the other direction. Bridgeway's national network combined six years of results: 60,000 graduates in each version. Version A came in at 36.0% and version B at 36.6%, a gap of only 0.6 points. The p-value was 0.03, so the gap is statistically significant. The two intervals look like this:

A huge sample makes the estimate very precise, so even a tiny gap can rule out zero. The network study is sure the gap is real. It is also sure the gap is small: about 6 more callbacks for every 1,000 graduates.

Whether 6 per 1,000 is worth recruiting a volunteer for every class is a question of practical significance: whether a difference is big enough, in the real world, to act on. No p-value answers that. People have to weigh the gain against the cost.

10. Wrap-up

  • Every gap has two explanations. The null hypothesis names the "just chance" one, and a test can only reject it or fail to.
  • A p-value says how unusual the data would be if there were no difference. A confidence interval says how big the difference could be.
  • A study can be too small to catch a real gap, or so big that it calls a tiny gap significant. Statistical significance is not practical significance.
