Name It, Tag It, Group It

An animal shelter keeps a profile for every pet: its name, age, weight, whether it has been adopted, and the day it arrived. A computer stores each of those a little differently. Three words help you talk about that clearly: variable, data type, and data structure. Mixing them up leads to real mistakes, like an ID number losing its first zeros.

3. A variable is a labeled box

Every week the shelter puts one pet on a "Pet of the Week" sign. The sign's title stays the same, but the pet on it changes. A variable works the same way: it's a named container that holds a value, and the value can change. The thing inside it right now is its value.

New in this example: pet_of_the_week = "Biscuit" means "store "Biscuit" in the box labeled pet_of_the_week." Here = means "store," not "is equal to" like in math. The quotes mark a piece of text.

Predict: the shelter writes these two lines, one week apart. After both lines, what does pet_of_the_week hold?

4. A data type says what kind of value it is

A data type is what kind of value a variable holds. You'll see five kinds all the time:

Data typeShelter example
Texta name, like "Biscuit"
Whole numbera count or an age, like 3
Decimala weight in pounds, like 12.5
True/falsehas this pet been adopted? True or False
Datethe day it arrived, like 2026-09-14

Look at the value itself, not the label. One rule helps a lot: if you would never do math with it, it's probably text, even when it's made of digits.

Mango weighs 4.2 pounds. What data type is that value?

Every pet also wears a tag with a number, like 00417. Nobody adds or averages tag numbers. They are labels.

Predict: if the computer stored 00417 as a whole number instead of text, what would it keep?

So the tag number belongs in the text type. Stored as text, 00417 stays 00417, and it can't be confused with a different pet's tag, 417.

5. A data structure groups values together

One pet has a name, an age, a weight, and more. Grouping several values together as one unit is a data structure. One pet's row is a small data structure called a record. The whole file, with one record for every pet, is a bigger one.

Here is the shelter's file, opened with cat:

$ cat pets.csv
name,age,weight,adopted,arrived
Biscuit,3,12.5,True,2026-09-14
Mango,1,4.2,False,2026-10-02
Pepper,7,30.0,False,2026-08-21

The first line holds the column names. Each line after it is one pet. Commas separate the values. That's why the file ends in .csv, which stands for "comma-separated values."

The line Mango,1,4.2,False,2026-10-02 holds five values about one pet. Is that line a data type or a data structure?

7. Wrap-up

  • A variable is a labeled box. The label stays the same while the value inside can change.
  • A data type says what kind of value something is: text, whole number, decimal, true/false, or date. If you'd never do math with it, treat it as text.
  • A data structure groups several values together, like one pet's row or the whole file of pets.
