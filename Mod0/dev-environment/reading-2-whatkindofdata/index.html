What Kind of Data Is This?

Build the vocabulary to describe values before you classify real columns in lecture.

Concept → example → practice → explain → save.

1. Three ideas that sound similar—but are different

Variable

A named container that holds a value, which can change.

daily_visitors = 428

Data type

What kind of value something holds: text, whole number, decimal, true/false, date.

Data structure

A way of organizing multiple values together, such as a table or list.

New analogy: Think of a library. A shelf label is like a variable name, the kind of item placed there is like a data type, and the shelving system organizing many items is like a data structure.

3. Five everyday data types

Classify the value itself, not what the column name sounds like.

Text

Words or identifiers you would not calculate with. Example: "BX-204".

Whole number

A count with no fractional part. Example: 37 lockers.

Decimal

A numeric measurement that may include a fractional part. Example: 12.6 km.

True/false

A two-state value. Example: is_open = true.

Date

A calendar date. Example: 2026-08-23.
