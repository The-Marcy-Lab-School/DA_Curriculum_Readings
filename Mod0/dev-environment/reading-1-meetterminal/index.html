1. Typing instead of clicking

A terminal is a window where you type instructions to your computer instead of clicking icons. Each instruction you type is a command. You type a command, press Enter, and the computer prints back a result. That printed result is the output.

Anything you do with a mouse in a folder has a typed version. The picture shows the same trip two ways.

2. How to read the terminal boxes on this page

This page never touches your real computer. Each dark box with a Terminal tab shows a command, and the steps below explain how to use it.

  1. Read the command in the box. On your own laptop, you'd type exactly that and press Enter.
  2. Answer the question under it first. The Run button stays locked until you do, so you guess before you see the answer.
  3. After you answer, the output appears right under the command, just as the terminal would print it.

In the output, the $ at the start of a line is the prompt. It's the terminal's sign that it's ready for a command. You never type the $ yourself.

3. Where am I? What's here?

The terminal is always "in" one folder. That folder is the working directory. Most commands act on it unless you name a different place. Two commands answer the first two questions you should ask in any new folder:

  • pwd answers "Where am I?" It prints the working directory's full location. It changes nothing.
  • ls answers "What's here?" It lists the files and folders inside the working directory. It changes nothing.

4. Moving around with cd

cd means "change directory." cd plants moves the working directory into the plants folder. It prints nothing when it works. That silence is normal.

You can write a location two ways:

  • A relative path starts from where you are now. plants means "the plants folder right here."
  • An absolute path spells out the whole route from the top of the computer, like /Users/sam/garden/plants. It works no matter where you are.

Two dots, .., mean "the folder one level up." So cd .. takes you back out.

Predict: you start in garden and run these three commands, one at a time. What does the last one print?

cd plants cd .. pwd
$ cd plants
$ cd ..
$ pwd
/Users/sam/garden

What does pwd print at the end?

Your turn: type a cd command

You're in garden and want to read the meeting notes.

  1. Type cd, then one space, then the folder name notes.
  2. Use lowercase letters. You don't need a / at the end.
  3. Press Check. You get 2 tries.

Why: cd plus a folder name moves the working directory into that folder.

5. Looking inside a file, and reading errors

cat plus a file name prints everything in that file. cat tomatoes.txt shows the tomato notes without opening any app.

Typos happen to everyone. When the terminal doesn't know a word, it says so, and the message names the exact word it saw. Reading that message is faster than guessing. The same habit tells you if a tool is installed: git --version prints a version number when git is installed, and an error when it isn't.

Predict: you mean to type pwd, but your fingers type pdw. What happens?

pdw
$ pdw
zsh: command not found: pdw

What happens when you run pdw?

The word zsh at the start is the name of the program running inside the terminal on a Mac. The error tells you to fix your typing, not your computer.

6. Practice in a simulated terminal

This terminal is pretend, but it acts like the real one. It's open in the garden folder. Do one step at a time.

  1. Type pwd and press Enter. You should see /Users/sam/garden.
  2. Type ls and press Enter. You should see README.md, notes, and plants.
  3. Type cd plants and press Enter. Nothing prints. That means it worked.
  4. Type ls and press Enter. You should see the two plant files.
  5. Type cat tomatoes.txt and press Enter. You should see the tomato notes.
  6. Type cd .. and press Enter to go back up to garden.
  7. Type git --version and press Enter. A version number means git is installed.

Why: these are the moves you'll make in every new project folder. Check where you are, look around, then go where you need to.

8. Wrap-up

  • The terminal is always in one folder, the working directory. pwd shows it, and ls lists what's in it.
  • cd moves you. A relative path starts from where you are, and an absolute path starts from the top. cd .. goes up one level.
  • cat prints a file. An error message names the exact word it didn't understand, so read it before you retry.
