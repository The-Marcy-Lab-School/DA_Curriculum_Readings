Meet Your Terminal

Learn what the terminal is, how paths work, and what a few commands actually mean before you use them live in class.

Read → try → get feedback → save your work.

1. The terminal is a text conversation with your computer

A terminal is a window where you type text commands directly to your computer. Instead of clicking a folder, you can type a command that asks the computer to show or move to it.

Why analysts use it: commands are precise, repeatable, and leave a useful record of what you did.
Prompt

The text before your cursor often includes your machine, current folder, and a $ or % waiting for input.

Command

The instruction you type, such as pwd.

Output

What the computer prints back after the command runs.

2. Vocabulary flip cards

Terminal

What is it?

A window where you type text commands directly to your computer.

Relative path

What is it?

A location described starting from where you are now.

Absolute path

What is it?

The full location from the top/root of the filesystem.

3. Three navigation commands

pwd

Print working directory. Ask “Where am I?” Use it before navigating when you are unsure of your location.

ls

List. Ask “What is here?” Use it before guessing a folder or filename.

cd NAME

Change directory. Move into a folder. It changes your location; it does not print a file.

5. Read errors instead of guessing

If a command is not found, the first move is to read the actual error. A typo and a missing tool can both produce useful clues.
