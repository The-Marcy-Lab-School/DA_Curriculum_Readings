Confidence Is Not Evidence

On Saturday, volunteers cleaned up a neighborhood park and wrote down every bag of trash they filled. Afterward, one volunteer asks an AI chatbot to sum up the day. In seconds it gives a number, sounds proud, and even names a news story to back it up. How an answer sounds tells you nothing about whether it's true.

~17–20 minutes Interactive No setup needed Saves your progress automatically

Skills you'll practice in this reading:

AI Literacy — Using an AI tool thoughtfully, and being able to explain in writing what it got right, what it missed, and how you verified its answer.

1. The chatbot's answer

The volunteer types: "How did our park cleanup go?" The chatbot replies:

"Your volunteers collected 64 bags of trash, the most of any park cleanup this year, according to a 2025 city news report."

It's specific, it sounds sure, and it would look great on a flyer. But nobody has opened the cleanup log yet.

2. Recall before you start

Telling structured data from unstructured data is a prerequisite skill for this reading. Check it before moving on.

The chatbot's reply is one paragraph of free text, with no rows or columns. What shape is it?

The cleanup log has one row per volunteer, with the same columns every time: volunteer, area, and bags. What shape is it?

3. A claim is not a fact yet

The chatbot's sentence is an unverified claim: a statement nobody has checked yet. It might be right or wrong, and the sentence alone can't tell you which. It becomes a verified fact only once someone confirms it against a real, checkable source, like the cleanup log itself.

Here's the key idea: confidence vs. accuracy. Confidence is how sure an answer sounds. Accuracy is whether it's correct. They're two separate things, as the picture shows.

A chatbot uses the same sure tone in every one of these boxes. So the tone can't tell you which box an answer belongs in. Only checking can.

Right now, before anyone opens the log, what do you know about "64 bags"?

4. Check it against the real file

The cleanup log is a file on the volunteer's laptop. You can open it with cat, which you already know. Press Run to open it, then add up the bags column.

cat cleanup_log.csv
$ cat cleanup_log.csv
volunteer,area,bags
Rosa,playground,9
Dev,basketball court,12
Kim,picnic tables,7
Omar,parking lot,10
Lena,walking path,8

What does the log say the total number of bags is?

That's what checking looks like, in four steps:

  1. Find the exact claim: the number, the name, or the source.
  2. Find a real source you can check yourself, like the original file.
  3. Compare the claim with what the source shows.
  4. Decide: use the claim, fix it, or drop it.

5. Sources that don't exist

Next, the volunteer searches the city's news site for the "2025 city news report." Nothing turns up. The chatbot made it up. A sure-sounding answer that is factually wrong is called a hallucination. A chatbot writes by predicting which words usually come next, so it can produce a source that sounds real without looking anything up.

Your turn: name it

  1. Read this sentence: "An AI answer that sounds sure but is factually wrong, like a made-up news report, is called a ____."
  2. Type the one missing word. Lowercase is fine.
  3. Press Check. You get 2 tries.

Why: having a name for it helps you remember to look for it.

6. Mixed check

Select every statement that is TRUE about checking the chatbot's answer.

7. Wrap-up

  • Any AI answer is an unverified claim until you check it against a real source.
  • How sure an answer sounds tells you nothing about whether it's accurate.
  • A hallucination is a sure-sounding answer that's wrong, sometimes with a made-up source.
