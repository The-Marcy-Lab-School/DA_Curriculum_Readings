What Shape Is This Data?

Before class, learn what structured, unstructured, and semi-structured data mean—and how a terminal helps you inspect files instead of guessing from their names.

Self-paced12–15 minutesRuns entirely in your browser
Read the short explanations first. Then practice in the simulated terminal.

1. First: what does “data shape” mean?

When analysts say a file has a certain shape, they are talking about how the information is organized.

Structured data

Structured data follows a consistent pattern. Think of a table where every record uses the same columns.

member,visits,plan Kai,6,monthly Rae,3,drop-in

Unstructured data

Unstructured data does not come pre-arranged into the same fields. Free text can contain useful information, but you may need to search or extract it.

Loved the new studio. The evening parking was difficult.

Semi-structured data

Semi-structured data has some organization—such as keys, tags, or headers—but not a fixed row-and-column table.

{ "member":"Kai", "visits":6, "notes":["evening","yoga"] }
Important: all three can be valuable data. The label tells you how the information is organized, not whether it is “good” or “bad.”

3. What is a terminal?

A terminal is a text-based way to tell your computer what to do. Instead of clicking through folders and menus, you type commands.

Why use one?

It is fast for repetitive work, works well with files and folders, and lets you combine simple commands into useful workflows.

What is a command?

A command is an instruction such as ls or grep. Extra pieces after the command tell it what file, pattern, or option to use.

What is output?

After you run a command, the terminal prints a result. That result is the command's output.

4. Five commands you will use

Learn what each command does before you type it.

ls

Meaning: list files and folders in your current directory.

Why use it? Before opening anything, see what files are actually there.

ls might show:

members.csv notes.txt events.json

head

Meaning: show the first part of a file.

Why use it? Preview a large file without printing the whole thing.

head -n 3 members.csv asks for the first 3 lines.

cat

Meaning: print a file's contents.

Why use it? Read a short text file quickly.

cat notes.txt prints the contents of notes.txt.

grep

Meaning: search text for lines that match a pattern.

Why use it? Find a word or phrase inside free-flowing text.

grep "parking" notes.txt finds lines containing parking.

wc

Meaning: count things in a file.

Why use it? wc -l counts lines; wc -w counts words.

wc -l members.csv counts lines in the CSV. wc -w notes.txt counts words in the note.

5. Why those commands help with data shape

You usually cannot classify a file well by its filename alone. The better habit is: list → preview/read → search/count → classify from evidence.
